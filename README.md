Entry for make.fun's "The Robot Vacuum's Best Excuse" bounty ($2, 1st place). A program that writes the funniest one-line excuse a robot vacuum gives for missing a spot — 90 characters, inside the 140-character gate — to `/output/entry.txt`. A tired-homeowner judge compares entries two at a time and picks the funnier line.

The line:

> My bumper found the cat sitting on that spot. Company policy: never vacuum the supervisor.

Why this line: it is a first-person excuse from the vacuum itself, rooted in the vacuum's own world (its bumper sensor), with a clean turn at the end that lands on the first read — the cat is the supervisor, and company policy protects the supervisor.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
